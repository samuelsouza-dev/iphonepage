# Página de Venda do iPhone

Página de produto do iPhone 14, desenvolvida para estudo e prática de HTML, CSS e JavaScript. É um projeto pessoal, sem vínculo com a Apple.

**Acesse online:** https://projeto-iphone-souza.netlify.app/

## Funcionalidades

- **Página do produto:** menu superior, nome, descrição, preço e botão de compra.
- **Troca de cor:** seis botões mudam a imagem do aparelho e a cor do círculo ao fundo.

## Como executar

Para ver a página completa, use o [link online](https://projeto-iphone-souza.netlify.app/), pois a pasta `imagens/` não está no repositório. Sem ela, a cópia local abre sem o logo e sem as fotos do aparelho.

Para abrir o código localmente, clone o repositório:

```bash
git clone https://github.com/samuelsouza-dev/iphonepage.git
```

Depois, abra o arquivo `index.html` no navegador.

## Limitações conhecidas

- **Apenas visual:** o menu e o botão **Comprar** não têm ação, e o preço é um texto fixo.
- **Telas pequenas:** o CSS não tem regras específicas (media queries) para celular.
